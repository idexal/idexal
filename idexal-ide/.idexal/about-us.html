Ecosystem

Idexal Brand

A unified ecosystem of developer tools, built open source

⌨️
Idexal IDE
Full-featured, AI-powered desktop IDE for Windows, macOS, and Linux. Built with Electron, React, Monaco Editor, and a Rust engine for blazing-fast performance. 96+ panels, 20 CLI commands, 18 AI providers.
github.com/idexal/idexal-ide 🌐 idexa.com

Idexa CLI
Powerful terminal-first AI coding assistant. Chat, analyze, search, review, and fix code — all from your terminal. Pipe-friendly, JSON output, 20 commands. Competes directly with Claude Code and Codex CLI.
github.com/idexal/idexa-cli ✉️ ide@idexal.com

Journey

Our Timeline

From first commit to world-class IDE

Phase 1 — Foundation
Project Initialization
Electron app scaffolding, Vite + React + TypeScript, Monaco Editor, Rust engine skeleton with Cargo workspace.
Phase 2-5 — Core Editor
Editor & AI Integration
Custom dark theme, tab management, split views, multi-cursor, 18 AI providers, inline completions, streaming responses.
Phase 6-10 — Intelligence
AI Agents & Code Intelligence
23-agent hierarchy, 6 agent types, code navigation, symbol search, hover tooltips, cross-references, Tree-sitter parsing.
Phase 11-15 — Platform
Git, DevTools & CLI
Full Git integration, terminal emulator, 20 CLI commands, project health checks, package manager, Docker, CI/CD panels.
Phase 16-18 — Polish
i18n, Security & Performance
13-language i18n, security audit fixes, Rust async CLI, clippy-clean, 195 tests, optimized release profiles.
Phase 19-35 — Competitive Edge
Feature Parity & Beyond
96+ panels, AI code actions, workspace context, SSH manager, database panel, multi-file search, pipe support, 53 contract tests.
