▶ Critical #1 webSecurity: false — Disabled Same-Origin Policy main.ts:30

Impact

Any content loaded in the renderer (malicious README HTML, third-party iframe, XSS payload) could read filesystem paths, make cross-origin network requests, and bypass CORS. This completely undermines the sandbox.

Fix Applied

- webSecurity: false, + webSecurity: true,

Status

▶ Critical #3 exec-command — Arbitrary Shell Execution main.ts:523

Impact

The exec-command IPC handler executed arbitrary shell commands from the renderer with full process.env and a 30s timeout. A compromised renderer became a full RCE.

Fix Applied

- ipcMain.handle('exec-command', async (_event, command: string, ...) => { - const { stdout, stderr } = await execAsync(command, { - env: process.env, ... - }) + // SECURITY: Arbitrary command execution intentionally NOT exposed. + // Use terminal IPC handlers for shell access.

Impact on Existing Code

  • gitService.ts — Updated to use gitReset() and gitCheckoutFile()
  • TerminalPanel.tsx — Updated to use terminalWrite()
  • taskRunnerService.ts — Updated to use terminal create/write/exit pattern

Status

✅ Fixed Handler removed. Preload API removed. Renderer types updated.

▶ Critical #4 Git Command Injection — Shell Interpolation main.ts:617

Impact

Commit messages, branch names, and file paths were interpolated directly into shell strings. A commit message containing "; rm -rf /; " achieved RCE.

Fix Applied

- await execAsync(`git commit -m "${message.replace(/"/g, '\\"')}"`) - await execAsync(`git checkout "${branch}"`) - await execAsync(`git add ${fileArgs}`) + await execFileAsync('git', ['commit', '-m', message]) + await execFileAsync('git', ['checkout', branch]) + await execFileAsync('git', ['add', ...files])
