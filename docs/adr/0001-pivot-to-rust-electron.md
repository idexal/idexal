# ADR 0001 — التخلي عن فرع VS Code والبناء من الصفر بـ Electron + Rust

**الحالة:** مُعتمَد | **التاريخ:** 2026-08-03

## السياق

المشروع بدأ كفرع كامل من مستودع VS Code (Code OSS) — نهج مبرَّر هندسياً (نفس نهج
Cursor وWindsurf، وأقرب المنافسين المعروفين). في نفس الجلسة، تم اكتشاف وإصلاح تكامل
حقيقي بين امتداد `idexal-agent` (مشاركة دردشة `@idexal` أصلية في VS Code) ونواة الذكاء
`idexal/ai-core`، وتم تشغيله بنجاح.

بعد ذلك، اتُّخذ قرار صريح من صاحب المشروع بالتخلي الكامل عن أساس VS Code والبدء من
الصفر بمكدس تقني مختلف (Rust + Electron)، وطُلب التنفيذ المباشر دون نقاش إضافي حول
الجدوى. تم حذف كامل شجرة عمل فرع VS Code من القرص (تاريخ Git الكامل يبقى محفوظاً في
commits سابقة على GitHub: `idexal/idexal`، فلا شيء ضاع فعلياً).

## القرار

- التطبيق الجديد يُبنى من الصفر بغلاف Electron (TypeScript + محرر Monaco المستقل، وليس
  محرر VS Code الكامل) ونواة وكلاء بلغة Rust (`core/`) كثنائي مستقل.
- الحدود بين الغلاف والنواة عبر عملية فرعية + NDJSON على stdout — نفس نمط الاتصال
  المُثبَت في `idexal/ai-core` الأصلي، معاد تطبيقه عبر حدود Rust/Node بدل TS/child أو
  FFI مباشر، لتفادي مشاكل توافق ABI للوحدات native التي واجهناها أثناء بناء فرع VS Code
  (توقف بناء `@vscode/policy-watcher` وغيرها بسبب رؤوس Electron).
- منطق `idexal/ai-core` و`idexal/cloud-provider` (المزودون، Fallback، الذاكرة، الأدوات)
  **لم يُحذف من الوعي التصميمي** — أُعيد استخراجه من تاريخ Git إلى `reference/` كمرجع
  تصميم فقط أثناء إعادة بناء نفس المنطق بلغة Rust في `core/`. هذا ليس تراجعاً عن قرار
  المستخدم؛ فقط تفادٍ لإعادة اختراع تصميم مُثبَت من الصفر حرفياً.

## الأثر

- فقدان مؤقت لكل ما كان مبنياً فوق VS Code (محرر كامل الميزات، نظام إضافات، Git مدمج)
  — يُعاد بناء ما يلزم منه تدريجياً فوق Monaco حسب الحاجة الفعلية، وليس كنسخة طبق الأصل
  من VS Code.
- محرك الوكلاء في `core/` يبدأ من الصفر وظيفياً (حالياً: بث NDJSON تجريبي فقط) — تكامل
  المزودين الحقيقي (Anthropic/OpenAI/محلي)، الذاكرة، وتنسيق الوكلاء المتعددين تُبنى من
  جديد بلغة Rust، بالاستفادة من التصميم المرجعي في `reference/`.
- تاريخ Git الكامل لفرع VS Code يبقى محفوظاً (محلياً وعلى GitHub) كسجل تاريخي، دون أن
  يكون أساساً للتطوير الحالي.
