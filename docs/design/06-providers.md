# 06 — المزودون والنماذج وسلسلة Fallback | Providers & Models

> Idexal — Agentic IDE. مرجع: [index](README.md) · [الإعدادات](03-settings.md)

## المبدأ التصميمي

**أي endpoint متوافق مع OpenAI = مزود من الدرجة الأولى.** لا قائمة بيضاء، لا إعادة
تصريف، لا بوابات. يضيفه المستخدم من صفحة الإعدادات بنقرة، بأولويته ونموذجه وترويساته
وحقوله الإضافية الخاصة به.

## أنواع المزودين

| النوع | الوصف | أمثلة |
|-------|-------|-------|
| `anthropic` | واجهة Anthropic Messages API الأصلية | Claude |
| `openai-compatible` | أي مزود يتكلم صيغة `/chat/completions` | OpenAI، OpenRouter، Groq، DeepSeek، Mistral، Together، Ollama، LM Studio، vLLM، بوابة خاصة |

> المرادفات المقبولة في الملف: `openai` / `openai-compatible` / `custom` — كلهن
> يُرسَلن إلى نفس المنفّذ.

## حقول المزود (سطح الإعدادات = 03-settings)

```json
{
  "id": "my-gateway",
  "type": "openai-compatible",
  "baseUrl": "https://my-gateway.internal/v1",
  "apiKey": "…",              // أو apiKeyEnv
  "apiKeyEnv": "MY_KEY",
  "model": "my-model-7b",
  "priority": 100,            // الأصغر يُجرَّب أولًا
  "headers": { "X-Title": "idexal" },
  "extraBody": { "top_k": 40 },
  "enabled": true
}
```

- **المفتاح**: إمّا حرفيًا `apiKey` أو اسم متغير بيئة `apiKeyEnv` (الأفضل أمنيًا).
  الواجهة لا تعرض المفتاح أبدًا — تعرف `hasKey` فقط.
- **headers**: تُدمج في كل طلب (بوابات/مؤسسات/org ids).
- **extraBody**: تُدمج في جسم الطلب (أزرار خاصة بالمزود).
- **enabled=false**: يحفظ المزود دون استخدامه.
- **local**: أي عنوان يحتوي localhost/127.0.0.1/0.0.0.0/::1 — لا يحتاج مفتاحًا.

## سلسلة Fallback (التبديل التلقائي)

1. المزودون تُرتَّب حسب `priority` تصاعديًا (في `config.rs` عند التحميل).
2. `Registry::stream_turn` يجرب: أولًا غير المبردين (pass 1)، ثم المبردين (pass 2)
   — حتى لا يفشل كل شيء بسبب cooldown كامل.
3. كل مزود يُجرَّب **مرة واحدة لكل جولة** (لا تكرار لصالح المبرد).
4. عند نجاح: `record_success` (تصفير العداد). عند فشل: `record_failure` →
   **cooldown تصاعدي**: 15ث، 30ث، 60ث… سقف 5 دقائق — يتضاعف مع التكرارات.
5. النجاح يُبث `{"type":"provider","name":...}` والواجهة تُظهر `⇄ name`.

### لماذا هذا أفضل من المرجع السابق
- المرجع تتبّع عدد الفشل لكنه استخدم دائمًا 30ث ثابتة. هنا الـ cooldown **يستعمل
  العدد فعليًا** (عامل 2^n).
- المرجع كان يسمح بإعادة المحاولة للمزود المبرد في نفس الجولة (مضاعفة زمن الانتظار
  والأخطاء). هنا `attempted` يمنع التكرار.

## مصادر الإعداد (الدمج)

| المصدر | الترتيب |
|--------|---------|
| `./idexal.config.json` (مساحة العمل) | 1 (يتغلب) |
| `~/.idexal/config.json` (المستخدم) | 2 |
| متغيرات البيئة (مزودون مشتقون) | 3 — يُضافون فقط إن لم يوجد id مكرر |

- ملف بمزود يحمل نفس id لمتغير بيئة → **يستبدله كليًا** (يمكن إعادة توجيه "anthropic"
  إلى بوابة شخصية).
- `config` المدمج يُفرز دائمًا بالأولوية.
- إعداد تالف (خطأ JSON) يُسجَّل على stderr ولا يُسقِط المزودين الآخرين.

## المزودون المشتقون من البيئة (الخبرة بلا إعداد)

| متغير | النتيجة |
|-------|---------|
| `ANTHROPIC_API_KEY` أو `ANTHROPIC_AUTH_TOKEN` | مزود `anthropic` (نموذج من `IDEXAL_ANTHROPIC_MODEL`) |
| `OPENAI_API_KEY` | مزود `openai` (نموذج من `IDEXAL_OPENAI_MODEL`) |
| (دائمًا) | مزود `ollama` محلي — `llama3.1` افتراضيًا، عنوان `IDEXAL_OLLAMA_URL` |

> Ollama محلي يُسجَّل **دائمًا كآخر خط** (أولوية 900): المفتاح صفر، يعمل بدون
> إنترنت — "أرضية" تضمن أن المنتج حي دائمًا.

## النماذج (Models)

- لا قيود على معرّفات النماذج: أي سلسلة تُرسل كما هي (النواة لا تتحقق من وجودها —
  المزود يرفض إن كان غير صالح، ويسقط الـ Fallback إلى التالي).
- افتراضيات البيئة: `claude-sonnet-4-5-20250929` · `gpt-4o-mini` · `llama3.1`.
- صفحة الإعدادات تتيح: نموذج افتراضي للجلسات، إضافة نماذج يدويًا، ونسخ إعدادات مزود.

## الاختبار الحي

`idexal-core test <provider-id>`:
- يبني إعدادًا **بمزود واحد** (يمنع المرور الصامت لمزود آخر يخفي العطل).
- يرسل جولة مصغّرة: "Reply with exactly: OK".
- يُخرج `{ok, provider, latencyMs, reply}` أو `{ok:false, error}`.
- يُستخدم من صفحة الإعدادات (زر "اختبار") ومن CLI.

## قواعد الصيانة

1. مزود جديد = نوع موجود (`anthropic` أو `openai-compatible`) — لا حاجة لكود.
2. منفّذ نوع جديد: ملف في `providers/` + عقد `stream_turn` + اختبارات + وثيقة هنا.
3. لا مفتاح API في أي مخرجات `config`/`providers`/`test`.
