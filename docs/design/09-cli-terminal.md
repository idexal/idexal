# 09 — الطرفية المدمجة وأمر idexal | Terminal & CLI

> Idexal — Agentic IDE. مرجع: [index](README.md)

## أمر `idexal` (الطرفية الخارجية)

غلاف Node بلا تبعيات حول النواة: يملك العرض فقط، وكل سلوك الوكيل في `idexal-core`
(يُؤمَّن: لا تكرار للمنطق، وعقد واحد).

```
idexal "<مهمة>"               وكيل واحد — بث مباشر
idexal run "<مهمة>"           صيغة صريحة
idexal agent "<مهمة>"         تعدد وكلاء: مخطط ← منفّذون ← مراجع
idexal review "<هدف>"         تحليل للقراءة فقط (لا كتابة ولا أوامر)
idexal providers              قائمة المزودين وحالتهم
idexal config                 الإعداد الفعلي كـ JSON (بلا مفاتيح)
idexal test <provider-id>     اختبار اتصال حي
idexal memory stats|recall "<q>"|add <kind> "<content>"
idexal --version · --help
```

### العرض (TUI في طرفية)

| الحدث | العرض |
|-------|-------|
| start | `providers: a → b → ollama` (رمادي) |
| phase | `▸ planning` (أزرق عريض) |
| plan | قائمة مرقّمة بالتبعيات `⟵ 1,2` |
| step-start / step-end | `▶ [1] …` · `✓/✗ [1]` |
| provider | `⇄ anthropic` (رمادي) |
| delta | نص متدفق بلا فواصل، مع أسطر فارغة ذكية حول الأحداث |
| tool-call | `⚙ write_file path` (كهرماني) مع وسم الخطوة في تعدد الوكلاء |
| tool-result | `✓/✗ name` |
| done | `● provider · N rounds/steps` |
| error | `⚠ …` (أحمر) |

- Ctrl-C يوقف الوكيل وليس يتيمًا (child.kill).
- ألوان تُفعَّل فقط عند `isTTY` — الأنابيب تخرج نصًا نظيفًا.
- `$IDEXAL_CORE` يوجّه النواة؛ إفتراضي: `core/target/release|debug` ثم PATH.

## الطرفية المدمجة (في التطبيق)

- جلسة shell كعملية فرعية بـ stdio مأنبوب، cwd = مجلد مساحة العمل.
  (ليست PTY كاملة بعد — بدون curses/تحكم مهام؛ تغطي build/test/git، والـ PTY
  مرحلة لاحقة بوحدة أصلية.)
- **الواجهة**: ناتج بخط monospace، اتجاه LTR، سطر إدخال بمحث `❯`، تفعيل عند التركيز.
- الإغلاق يقتل كل الجلسات (لا عمليات يتيمة عند خروج التطبيق).
- أفق: PTY حقيقي، تبويبات طرفية متعددة، مشاركة المخرجات مع الوكيل.

## علاقة الطرفيتين بالنواة

```
idexal "<مهمة>"  ──spawn──►  idexal-core stream  ──NDJSON──►  عرض TUI
الطرفية المدمجة  ──ipc──►    محطة Electron         (cwd=المساحة)
لوحة الوكيل     ──ipc──►    idexal-core agent|stream ──NDJSON──► سجل + خطة
```

## القواعد

1. أي أمر جديد في النواة يُكشَف في CLI فورًا (نفس العقد — لا عقد ثانٍ).
2. الطرفية المدمجة تُطلق من المجلد المفتوح؛ CLI من مجلده الحالي.
3. أخطاء النواة تُعرض بصيغة مفهومة (لا أكوام JSON).
4. الأوامر التدميرية (push/publish/…) تبقى خارج CLI حتى توجد بوابة تأكيد (وثيقة 07).
