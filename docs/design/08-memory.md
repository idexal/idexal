# 08 — الذاكرة طويلة الأمد | Long-Term Memory

> Idexal — Agentic IDE. مرجع: [index](README.md) · [الإعدادات](03-settings.md)

## المبدأ

الوكلاء يحملون المعرفة عبر الجلسات: حقائق، قرارات، تفضيلات، وملخصات جلسات سابقة.
الذاكرة **دائمة** (SQLite في `~/.idexal/memory.db`) وتُسترجَع تلقائيًا في كل جولة
مهمة، فتصبح الجلسة التالية أوضح وأسرع — دون أن يُطلب من المستخدم إعادة شرح شيء.

## أنواع الذاكرة

| النوع | المعنى | أمثلة |
|-------|--------|-------|
| `fact` | حقيقة عن المشروع أو بيئته | "أمر البناء هو `cargo build --release`" |
| `decision` | قرار معماري/تنفيذي | "اعتمدنا Rust للنواة وليس Node" |
| `preference` | تفضيل المستخدم | "أجب بالعربية دائمًا"، "لا تستخدم tabs" |
| `session` | ملخص جلسة سابقة | "مهمة: … النتيجة: …" |

## دورة الحياة

```
جولة وكيل ← استرجاع (recall) ← حقن في prompt النظام ← تنفيذ
     │                                                     │
     └── عند نجاح الجولة: حفظ ملخص (remember: session) ─────┘
```

- **الاسترجاع**: قبل بدء الوكيل (ولكل خطوة منفّذ في تعدد الوكلاء) — يُسترجَع من
  الجذر (لا يُشارَك اتصال SQLite عبر await؛ النص الناتج يُمرَّر).
- **الحقن**: تُضاف ككتلة في **prompt النظام** (وليس رسالة المستخدم) كي لا يلتبس
  الأمر على النموذج.
- **الحفظ**: عند نجاح المهمة فقط — حفظ الفشل يسمم الذاكرة بالضوضاء. أفق: حفظ
  القرارات/الحقائق الاستنتاجية تلقائيًا من المخرجات.

## الاسترجاع (الوضع الحالي: معجمي)

- **التقطيع**: أحرف ألفبائية رقمية فقط، تجاهل 1-حرف، **بوعي Unicode** — النص العربي
  يُفهرس ككلمات لا ككتلة واحدة (اختبار `arabic_content_is_tokenized_as_words`).
- **التسجيل**: كلمات المضمون في عمود `keywords` عند الحفظ.
- **التسجيل العكسي**: تداخل كلمات الاستعلام مع المخزون ÷ طول الاستعلام.
- **وزن الحداثة**: انحلال على أسبوع (`1 − age_days/7`) × 0.3 — أحدث يتفوق قليلًا.
- **الترتيب والحد**: الفرز تنازليًا ثم `limit` (افتراضي 5، قابل للضبط في الإعدادات).
- **إحصاءات الوصول**: كل نتيجة تُحدّث `last_accessed_at` و`access_count` — أساس
  لترجيح "المفيد كثيرًا" مستقبلًا.

## المخطط (Schema)

```sql
CREATE TABLE memories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,              -- fact|decision|preference|session
  content TEXT NOT NULL,
  project TEXT,                    -- معزولة لكل مشروع
  created_at INTEGER NOT NULL,
  last_accessed_at INTEGER NOT NULL,
  access_count INTEGER NOT NULL DEFAULT 0,
  keywords TEXT NOT NULL DEFAULT ''
);
CREATE TABLE memory_embeddings (   -- محجوزة للاسترجاع الدلالي (مرحلة لاحقة)
  memory_id INTEGER PRIMARY KEY REFERENCES memories(id) ON DELETE CASCADE,
  dimension INTEGER NOT NULL,
  model TEXT,
  vector TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);
```

- **توافق قديم**: المخطط مطابق لتنفيذ Node السابق (`type` لا `kind`؛
  `last_accessed_at NOT NULL`) — ذاكرة موجودة تكمل عملها بلا هجرة.
- **Embeddings**: الجدول محجوز؛ إضافته لاحقًا لا يتطلب ترحيل الصفوف الموجودة.

## العزلة حسب المشروع

- كل سجل يحمل `project` (اسم مجلد الجذر) — الاسترجاع يُفلتر بالمنطق:
  `(?1 IS NULL OR project IS NULL OR project = ?1)`.
- أي: ذاكرة عامة (project NULL) تصل لأي مشروع؛ ذاكرة مشروع تبقى لمشروعها.
  أفق: مفتاح "عزل تام" في الإعدادات.

## سطح الإدارة

| المسار | الأمر |
|--------|-------|
| النواة | `idexal-core memory stats` · `recall "<query>"` · `add <kind> "<content>"` |
| الطرفية | `idexal memory stats|recall|add` |
| الواجهة | قسم الذاكرة في صفحة الإعدادات: إحصائيات/بحث/إضافة/حذف/تصدير |

## القواعد التشغيلية

1. فشل فتح الذاكرة لا يوقف الوكيل — يتحول إلى "بلا ذاكرة" مع ملاحظة على stderr.
2. الذاكرة **أفضل جهد**: خطأ كتابة لا يُسقط المهمة.
3. لا تُخزَّن أبدًا: المفاتيح، المحتوى الحساس للواجهة، أو مخرجات الأدوات الكاملة —
  فقط الملخصات/الحقائق المتناسبة.

## أفق التطوير

- استرجاع دلالي (Embeddings) عبر جدول `memory_embeddings`.
- نسيان تلقائي / ضغط للذاكرة القديمة جدًا أو غير المفعّلة.
- "ذاكرة مشروع" منفصلة عن "ذاكرة المستخدم".
- اقتراحات ذاكرة للمستخدم: "هل أتذكر أنك تفضل X؟" بتأكيد منه.
