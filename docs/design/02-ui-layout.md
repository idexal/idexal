# 02 — تصميم الواجهة والتوزيع | UI Layout

> Idexal — Agentic IDE. مرجع: [index](README.md)

## الفلسفة البصرية (طراز ZCode / Claude Code)

- **داكن، كثيف، هادئ**: خلفية كحلية عميقة، إبراز بألوان معدودة، خطوط monospace.
- **الكثافة للبيانات، لا للزخرفة**: كل بكسل إما معلومات أو تحكم — بلا ظلال زائدة.
- **الحيوية**: كل حدث وكيل يظهر فورًا (بث)، وكل تغيير ينعكس على Git والمحرر والمعاينة.
- **RTL أصيل**: الواجهة عربية يمين-إلى-يسار، مع اتجاه LTR للكود والأوامر والعناوين التقنية.
- **التسلسل البصري**: عمود النشاط (Rail) أضيق ← لوحة جانبية ← مركز (محرر/معاينة) ← لوحة الوكيل.

## عناصر الواجهة بالتفصيل

### 1. شريط العنوان (titlebar)
| العنصر | الوظيفة |
|--------|---------|
| ◆ Idexal | الشعار والاسم |
| اسم المجلد | المجلد المفتوح حاليًا |
| فتح مجلد… | اختيار مساحة عمل جديدة (يُغلق التبويبات ويُحدّث الشجرة وGit) |
| ⚙ الإعدادات | فتح صفحة الإعدادات الشاملة (الوثيقة 03) |

- منطقة سحب للنافذة `-webkit-app-region: drag`، مع `no-drag` للأزرار.

### 2. عمود النشاط (Rail) — 46px
| الزر | اللوحة | الوصف |
|------|--------|-------|
| 📁 | المستكشف | شجرة الملفات (مجلدات قابلة للطي، تجاهل `node_modules`/`.git`/`target`) |
| ⎇ | Git | حالة المستودع + فروق ملوّنة |
| ◆ | مهام الوكلاء | خطة متعددة الوكلاء حيّة (dots: قيد التنفيذ/تم/فشل) |
| ⚙ | الإعدادات | صفحة الإعدادات (وثيقة 03) |

- الزر النشط يُبرز بشريط أكسنت يميني (RTL).
- عند ظهور خطة جديدة تنتقل اللوحة تلقائيًا إلى "مهام الوكلاء" دون سرقة التركيز.

### 3. اللوحة الجانبية (Side) — 240px قابلة للتوسعة لاحقًا
- **المستكشف**: صفوف بمسافات بادئة حسب العمق، أيقونات ▸/▾ للمجلدات، نقرة=فتح.
- **Git**: صف لكل ملف `[الحالة][المسار]` — M أصفر، A/?? أخضر، D أحمر. نقرة ← فتح الفروق في الـ dock.
- **مهام الوكلاء**: صف لكل خطوة: `(dot) [id] الوصف` — تشغيل (أكسنت نابض) / تم (أخضر) / فشل (أحمر).

### 4. المركز (Center)
- **شريط التبويبات**: اسم الملف، نقطة تعديل ●، زر إغلاق ×، تبويب نشط بظل أكسنت علوي.
- **محرر Monaco**: سمة `vs-dark`، خط Cascadia/Consolas، minimap، Ctrl/Cmd+S للحفظ.
  - خريطة امتداد → لغة (ts/js/rs/py/go/json/html/css/md/yaml/toml/sh…).
- **المعاينة الحية (webview)**: لوحة منفصلة بعنوان URL قابل للتحرير + زر انتقال/إعادة تحميل/إغلاق.
  - زر "معاينة حية" في الـ dock يُظهر/يُخفي اللوحة.
- **الـ dock السفلي (220px، قابل للطي)**: تبويبا الطرفية والفروق.

### 5. لوحة الوكيل (Agent Pane) — 380px
| المنطقة | المحتوى |
|---------|---------|
| الشريط العلوي | شارة `idexal-core` · وضع التشغيل (وكيل واحد / تعدد الوكلاء) · مفتاح تبديل |
| السجل | رسائل المستخدم (يمين، فقاعة) · ردود الوكيل · أسطر الأحداث (أدوات/مراحل/مزودين) بتمييز لوني |
| شريط الحالة | فرع Git ⎇ · عدد الملفات المعدّلة · حالة الجولة (idle/running…) |
| الإدخال | حقل نص + زر إرسال + سطر "local · no account · Idexal Core" |

- **ترميز الألوان في السجل**: أداة = كهرماني، نجاح أداة = أخضر، فشل = أحمر، مرحلة = أكسنت، مزود = رمادي `⇄ name`.
- تفعيل "تعدد الوكلاء" يغيّر وضع النواة من `stream` إلى `agent` (مخطط←منفّذون←مراجع).

## التفاعلات والميكرو-إنترأكشنز

- hover على الصفوف والأزرار: تفتيح لوني وخلفية خفيفة.
- `:focus-within` على حقل إدخال الوكيل: إطار أكسنت.
- شريط تمرير مخصص (داكن بحدود دائرية).
- حركة "dot" قيد التنفيذ: توهج أكسنت (نابض).
- شفافية أزرار `:disabled` عند التشغيل (منع إرسال مزدوج).

## لوحة الإعدادات (المخطط)

صفحة مستقلة كاملة (ليست نافذة عائمة) تفتح بدل المركز، بأقسام قابلة للطي:
المزودون ← النماذج ← الوكيل ← الصلاحيات ← الذاكرة ← Git/المعاينة ← المظهر ← مفاتيح الاختصار.
التفاصيل الكاملة في [03-settings.md](03-settings.md).

## نظام الألوان (توكينات)

| المتغير | القيمة | الاستخدام |
|---------|--------|-----------|
| `--bg` | `#0c0e17` | الخلفية الرئيسية |
| `--bg-raised` | `#12141f` | ألواح وشريط العنوان |
| `--bg-input` | `#10121d` | حقول الإدخال |
| `--line` | `#1e2133` | الحدود |
| `--ink` / `--ink-soft` / `--ink-faint` | سلسلة الرمادي | النص حسب الأولوية |
| `--accent` | `#3454e0` | أكسنت (نشاط، مرحلات، إرسال) |
| `--accent-2` | `#5ee6a0` | نجاح، إضافات Git، صلاحيات |
| `--warn` | `#e0a55e` | تحذير، تعديلات Git |
| `--danger` | `#ff8fa3` | فشل، حذف |
| `--mono` | Cascadia/Consolas | كود، أوامر، أحداث |

## قواعد الصيانة

1. كل عنصر جديد يُضاف للتوكينات أولاً — لا ألوان مبعثرة.
2. الأحداث تُرسم بـ DOM nodes لا innerHTML (منع حقن المحتوى من مخرجات الأدوات).
3. أي لوحة جديدة: زر في Rail + `data-panel` + مقطع CSS — نمط موحّد.
