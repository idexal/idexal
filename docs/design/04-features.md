## مميزات الوكيل (Agentic)

- **أدوات حقيقية**: `read_file` · `write_file` · `list_dir` · `run_command` —
  موصوفة بـ JSON Schema، منفَّذة في النواة، محمية ضد تجاوز المسار.
- **حلقة أدوات**: المحادثة ↔ أدوات حتى رد نهائي، بحد `max_tool_rounds`.
- **أدوات للقراءة فقط** (`--read-only`): للمراجعات والتحليلات — لا كتابة ولا أوامر.
- **مراحل مرئية**: planning → executing → reviewing تُبث وتُعرض بلون مميز.
- **خطة حية**: قائمة خطوات مع تبعيات `depends_on`، تلوّن لحظي (تشغيل/تم/فشل).
- **تحديث ذاتي للواجهة**: بعد كل نتيجة أداة → إعادة قراءة Git والتبويبات المفتوحة
  (دون مسح تعديلات المستخدم غير المحفوظة).

## مميزات المزودين (وثيقة 06)

- **بلا قيود**: أي OpenAI-compatible endpoint = مزود من الدرجة الأولى.
- **Fallback تلقائي**: فشل مزود ← التالي، مع cooldown تصاعدي (15ث ← 5د).
- **إعادة ترتيب بالأولوية**: الأصغر أولًا؛ ملف بنفس id يستبدل متغير البيئة.
- **اختبار اتصال حي** من صفحة الإعدادات (`idexal-core test <id>`).
- **يعمل بلا حساب**: Ollama محلي مُسجَّل كخط أخير دائمًا — صفر مفاتيح.

## المميزات المستقبلية (Roadmap)

1. Git تعديلي مع Diff مرئي وقبول/رفض لكل تغيير (أولوية عالية).
2. طرفية PTY حقيقية.
3. تصحيح أخطاء عبر DAP.
4. عوامل لغة Monaco (اكتمال تلقائي، تشخيصات).
5. وكلاء فرعيون (subagents) يستدعيها المنفّذ لتفويض مهام جزئية.
6. استرجاع دلالي للذاكرة (Embeddings).
7. لوحة أوامر (Ctrl+Shift+P) وأوامر قابلة للتخصيص.
8. حزم Windows/macOS/Linux + تحديث تلقائي + موقع idexal.com.
9. أوامر `/slash` داخل إدخال الوكيل (مثل `/plan` `/review` `/memory`).
10. وضع "مراقبة الملفات": إعادة بناء الشجرة/المعاينة تلقائيًا عند تغيّر القرص.

## مبدأ التطوير

كل ميزة تمر بثلاث خطوات: **النواة أولًا** (قابلة للاختبار والقياس)، ثم **الواجهة**
(عرض/تفاعل)، ثم **التوثيق** (هذه الوثيقة + ADR إن لزم). لا تُعلَن ميزة منجزة إلا
بعد تحققها الفعلي.
