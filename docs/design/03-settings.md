# 03 — صفحة الإعدادات الشاملة | Settings

> Idexal — Agentic IDE. مرجع: [index](README.md)

## المبدأ

**كل تغيير يجب أن يتم من داخل البرنامج** — صفحة إعدادات احترافية، مفصّلة، متقدمة،
مباشرة، تُفتح من زر ⚙ في شريط العنوان (وأيقونة Rail). ملف `~/.idexal/config.json`
هو مجرد أثر مكتوب تلقائيًا بمعرفة الصفحة — المستخدم لا يلمسه يدويًا أبدًا.

- التحميل: عبر `idexal-core config` (الإعداد الفعلي المدمج — بلا مفاتيح API).
- الحفظ: الصفحة تكتب `config.json` وتتحقق فورًا أن النواة ما زالت تقرأه بنجاح.
- الاختبار: زر لكل مزود يستدعي `idexal-core test <id>` (رحلة ذهاب-إياب حية).

## مخطط الصفحة

```
┌─────────────────────────────────────────────────────────────┐
│ ⚙ الإعدادات                    [الملف: ~/.idexal/config.json] │
├─────────────────────────────────────────────────────────────┤
│ ▸ المزودون (Providers)         [＋ إضافة مزود]                │
│   ┌───────────────────────────────────────────────────────┐ │
│   │ [anthropic] نوع: Anthropic  النموذج: claude-sonnet…  │ │
│   │ Base URL: https://api.anthropic.com  [اختبار] ✓ 120ms │ │
│   │ المفتاح: (متغير ANTHROPIC_API_KEY) ●●●●●  [حفظ]      │ │
│   │ الأولوية: 1  [مفعّل]  [تحرير] [حذف]                  │ │
│   └───────────────────────────────────────────────────────┘ │
│   ... (كل مزود بطاقة)                                        │
│ ▸ النماذج والمخططات (Model presets)  [＋ إضافة نموذج]        │
│ ▸ سلوك الوكيل (Agent)                                        │
│   أقصى جولات أدوات: 12 · أقصى وكلاء متوازون: 3 · مراجع: ✓    │
│ ▸ الصلاحيات (Permissions)                                    │
│   read_file ✓ list_dir ✓ write_file [يتطلب موافقة] run_cmd…  │
│ ▸ الذاكرة طويلة الأمد                                        │
│   [إحصائيات] [استرجاع] [بحث] [حذف الكل] [تصدير]              │
│ ▸ Git والمعاينة والطرفية                                     │
│ ▸ المظهر (السمة، اللغة، الخط، حجم الخط)                      │
│ ▸ الاختصارات (Keyboard shortcuts)                            │
├─────────────────────────────────────────────────────────────┤
│ [استعادة الافتراضي]          [إلغاء]   [حفظ التغييرات]      │
└─────────────────────────────────────────────────────────────┘
```

## 1) قسم المزودون (قلب المنتج)

كل مزود = بطاقة قابلة للطي/التحرير تحتوي:

| الحقل | الوصف | ملاحظات |
|-------|-------|---------|
| المعرّف (id) | اسم فريد، مثل `anthropic` أو `my-gateway` | يُميّز المزود؛ ملف بنفس id يستبدل متغير البيئة |
| النوع | `anthropic` أو `openai-compatible` | أي endpoint متوافق OpenAI = openai-compatible |
| Base URL | عنوان الـ API | اختياري؛ افتراضي حسب النوع |
| النموذج | معرّف النموذج | مثل `claude-sonnet-4-5-20250929` |
| المفتاح | إمّا متغير بيئة أو مفتاح مباشر | الواجهة لا تعرض المفتاح أبدًا: "hasKey ✓" فقط |
| الأولوية | رقم — الأصغر يُجرَّب أولاً | سحب/إفلات أو أزرار ▲▼ لإعادة الترتيب |
| مفعّل | مفتاح تشغيل | تعطيل يحفظ المزود دون استخدامه |
| Headers | خريطة JSON | للبوابات المخصصة (مثل `X-Title`) |
| Extra body | خريطة JSON | خيارات خاصة بالمزود (`top_k` وغيرها) |

**أزرار لكل مزود**:
- `اختبار` — يستدعي `idexal-core test <id>` ويعرض زمن الاستجابة أو الخطأ.
- `تحرير` — توسيع الحقول المتقدمة (headers/extraBody).
- `حذف` — مع تأكيد.
- `▲/▼` — إعادة ترتيب الأولوية (سلسلة Fallback).

**إضافة مزود**: قوالب جاهزة (Anthropic، OpenAI، OpenRouter، Groq، DeepSeek، Mistral،
Together، Ollama محلي، LM Studio، بوابة مخصصة فارغة) + "مخصص".

## 2) قسم النماذج والمخططات

- قائمة النماذج المتاحة لكل مزود (من `providers`/`config`) مع إمكانية **إضافة معرّف
  نموذج يدوي** (بلا قيود: أي سلسلة تُقبل وتُرسل كما هي).
- "النموذج الافتراضي" للجلسات الجديدة.
- نسخ/لصق إعدادات مزود كامل (JSON) لمشاركتها أو تكرارها.

## 3) قسم سلوك الوكيل

| الإعداد | الافتراضي | المعنى |
|---------|-----------|--------|
| maxToolRounds | 12 | أقصى جولات أدوات لكل وكيل قبل إجباره على رد نهائي |
| maxParallelAgents | 3 | أقصى منفّذين متوازنين في موجة واحدة |
| useReviewer | true | تفعيل مرحلة المراجع بعد التنفيذ |
| system prompt المخصص | — | سطر يضاف إلى prompt النظام (شخصية/قيود المشروع) |
| لغة الرد المفضلة | العربية | تُمرَّر للوكيل في prompt |

## 4) قسم الصلاحيات (يرتبط بـ 07-permissions)

لكل أداة وضع موافقة:
- **تلقائي** (دون سؤال) — القراءة والسرد افتراضيًا.
- **يتطلب موافقة** — الكتابة والأوامر قابلة للضبط.
- **محظور** — تعطيل الأداة كليًا.

إعدادات إضافية: قائمة أوامر محظورة (blocklist regex)، المهلة الافتراضية للأوامر،
وضع `--read-only` للجلسات المراجَعة، و"وضع الأمان الكامل".

## 5) قسم الذاكرة طويلة الأمد

- إحصائيات حية (`idexal-core memory stats`).
- بحث/استرجاع (`recall "<query>"`) مع عرض النتائج مرتبة بالأهمية.
- إضافة ذاكرة يدويًا (`add <kind> "<content>"`).
- حذف الكل / تصدير (نسخ احتياطي JSON/SQLite).
- مفتاح "تفعيل الذاكرة" و"عدد النتائج المسترجعة لكل جولة" (افتراضي 5).

## 6) قسم Git والمعاينة والطرفية

- **Git**: وضع القراءة فقط مقابل وضع التعديل (إضافة/إيداع مع تأكيد صريح في الواجهة)،
  فرع افتراضي، تنسيق الرسائل.
- **المعاينة**: عنوان افتراضي للمعاينة الحية، تفعيل "إعادة تحميل تلقائي عند الحفظ"،
  ومتصفح مدمج (webview) بصلاحياته.
- **الطرفية**: المحطة الافتراضية (cmd/bash)، حجم الخط، "فتح تلقائي عند أول أمر".

## 7) قسم المظهر

- السمة: Dark (افتراضي) / Light / متابعة النظام.
- اللغة: عربية (RTL) / English (LTR) — تُطبَّق فورًا.
- خط المحرر/الطرفية وحجم الخط.
- إظهار/إخفاء: minimap، شريط Git، أرقام الأسطر، لوحة الوكيل.

## 8) قسم الاختصارات

| الاختصار | الإجراء |
|----------|---------|
| Ctrl/Cmd+S | حفظ التبويب النشط |
| Ctrl/Cmd+Enter | إرسال مهمة للوكيل |
| Ctrl/Cmd+` | تبديل الطرفية |
| Ctrl/Cmd+Shift+P | فتح لوحة الأوامر (مستقبل) |
| F5 | إعادة تحميل المعاينة |
| Ctrl/Cmd+O | فتح مجلد |

## عقد الحفظ

1. الواجهة تجمع الحالة من النماذج → JSON مطابق لمخطط `Config` (camelCase).
2. `settings:save` يكتب `~/.idexal/config.json` (ويُنشئ المجلد).
3. يستدعي `idexal-core config` للتحقق — إن فشل التحليل، يُعرض الخطأ ولا يضيع شيء.
4. الواجهة تعيد التحميل من الحالة الفعلية المدمجة (لترى أثر متغيرات البيئة).

## قواعد الصيانة

- كل حقل إعداد جديد: يُضاف إلى `config.rs` (مع `#[serde(default)]` للتوافق) ←
  ثم إلى بطاقة الصفحة ← ثم يُوثَّق هنا.
- لا مفتاح API يُرسل إلى الواجهة أبدًا: الواجهة تعرف `hasKey` فقط.
- صفحة الإعدادات لا تحتاج إعادة تشغيل: الحفظ يعيد التحميل مباشرة.
